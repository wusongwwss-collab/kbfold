# KBFold · 知识库整备台

> 一个改错了能一键退回去的知识库整备台。把散乱的项目资料编译成知识库。

**状态：v0.1.0 设计已定稿，代码整理中** —— 本仓库先公开定位、许可与文档；代码整理完成后随首个发布推出。

## 它做什么

- 扫描你的项目资料目录，判定每个文件该归哪个库、哪一层，产出可预览的重整计划
- 先看后动：`kbfold plan` 预演，`kbfold apply` 才落盘，每一步都记进追加式日志，`kbfold undo` 一键整批退回
- 判定不猜：置信度不够的直接进 `_inbox/` 摊开候选，不硬归类
- 全文检索：语义 + 全文 + 关键词三路融合，每条结果都带 `[n]` 引用编号
- 默认零风险：只读扫描、删除能力不存在（代码里没有 unlink）、除本地嵌入模型外零外连

## 快速感受（仓库正式开源后可用）

```bash
npx kbfold plan ./fixtures --demo
```
